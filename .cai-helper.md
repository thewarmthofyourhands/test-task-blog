### Project tree structure
/devops -- папка с докером которая подготавливает к запуску проект и его сервисы
/code -- список сервисов проекта
/code/api -- сервис бекэнда кора и сессий
/code/app -- сервис фронтэнда кора и сессий
/code/auth-api -- сервис бекэнда авторизации
/code/auth-app -- сервис фронтэнда авторизации
/code/ide-api -- сервис бекэнда ide
/code/ide-app -- сервис фронтэнда ide
/code/auth-api -- сервис бекэнда авторизации
/code/auth-app -- сервис фронтэнда авторизации
/code/workspace-api -- сервис бекэнда авторизации
/code/workspace-app -- сервис фронтэнда воркспейса
/code/landing -- сервис фронтэнда лендинга
/code/cdn -- общий cdn с важными библиотеками для фронтэнда
/code/chess-app -- сервис фронтэнда игры в шахматы

/devops/docker/local/docker-compose.yaml -- если нужно, можешь сюда глянуть для лучшего понимания
